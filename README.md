## 📌 **App Idea**

A simple **console-based application** that allows users to manage daily tasks (ToDo list).
Users can **add, view, complete, and delete tasks** easily from the terminal.

---

## 👥 **Target Users**

* Students
* Developers
* Anyone needing a simple task manager

---

## ⚙️ **Features**

### ✅ Core Features

* ➕ Add a task
* 📋 View all tasks
* ✔️ Mark task as completed
* ❌ Delete a task

---

## 🛠️ **Tech Stack**

* **Language:** C# (if allow or we will use java or python)
* **IDE:** Visual Studio
* **Version Control:** GitHub
* **Environment:** Virtual Machine (VM)
* **Storage:** Local file (JSON or TXT)
